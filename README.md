# Sticketas — catálogo estático

Primera dirección visual basada en el brief:
**Playful editorial + sticker culture + premium stationery.**

## Cómo probarlo
Abrí `index.html` directamente en el navegador.

También podés servir la carpeta con:
- VS Code + Live Server
- `python -m http.server`
- GitHub Pages / Netlify / Vercel

## Qué incluye
- Home editorial
- Hero de marca
- Colecciones
- Catálogo filtrable
- Carrito demo persistido en `localStorage`
- Buscador visual
- Sección de inspiración / lifestyle
- Personalizados
- Newsletter demo
- Responsive
- Microinteracciones
- Stickers decorativos drag & drop

## Antes de producción
Reemplazar:
1. El wordmark textual por el logo oficial de Sticketas.
2. Los SVG mockup por fotografías reales.
3. Productos, precios y descripciones.
4. Enlaces de Instagram / TikTok / Pinterest.
5. Enlace de WhatsApp.
6. Acción final del carrito.

No necesita backend para funcionar como catálogo.
